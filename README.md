# Atividade Continuada 2 - Mobile Development

Objetivo: criar um app em React Native com Expo que consome a API TheMealDB, lista as receitas em uma FlatList (nome e imagem) e, ao clicar em uma receita, navega para uma tela de detalhes passando os dados por parâmetro.

Requisitos: Expo, React Native e axios; 2 telas (Home e Detalhes); código funcionando sem erros. Tempo estimado: cerca de 2 horas.
